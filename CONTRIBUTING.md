# Contributing

1. Create a focused branch from `main`.
2. Keep changes small and add tests for behavior changes.
3. Run all backend and frontend quality gates documented in the README.
4. Use Conventional Commits, for example `feat(frontend): add request editor`.
5. Do not commit credentials, local data, generated output, or dependency directories.

Security controls must not be weakened to make a test pass. Document the threat model when adding outbound request behavior.
